Mã hóa & tải lên tài liệu mới

Chọn một hoặc nhiều file PDF; các file được mã hóa lần lượt ngay trên server (AES-256-GCM) và lưu lại để tải về bất cứ lúc nào — không cần dùng CLI. Tối đa 300MB/file. Nhiều file: tên tài liệu lấy theo tên từng file.
